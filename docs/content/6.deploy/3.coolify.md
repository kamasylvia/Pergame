[Coolify](https://coolify.io/) is an alternative way to deploy Pergame on your own server.

Pergame is available directly in Coolify's list of services. This means that you can create an Pergame deployment from Coolify without manually copying or modifying the `docker-compose.yml`.

The deployment still uses the same Pergame configuration and environment variables as a regular Docker deployment.

## Create the service

1. Open your Coolify instance.
2. Select the project and environment where you want to deploy Pergame.
3. Create a new resource.
4. Select **Pergame** from the available services.
5. Select the server where Pergame should run.
6. Configure the required domains and environment variables.
7. Deploy the service.

You do not need to manually edit the Pergame Docker Compose file.
