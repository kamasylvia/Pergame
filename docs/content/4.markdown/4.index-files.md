Each workspace and category automatically owns a small document that lists everything inside it. Pergame creates it with the folder and shows it at the top of the folder in the sidebar.

The file is a normal document, so you can add notes to it: the list is produced by an `index` block, and anything you write outside the block stays.

````md
```index
```
````

That block expands to a clickable listing of the folder: sub-folders first (opening one goes to *its* index page), then documents and files. The listing covers the whole subtree, so nested folders stay reachable from a single index page.

## Renaming the index file

The name belongs to the folder, not to the document. Change it once in **Settings → Documents → Folder index file name** and every existing index file is renamed with it; folders created later use the same name. Renaming the document directly is not possible, and neither is moving or deleting it — delete the folder instead.

## Hiding index files

Index files are visible in the sidebar by default. Turn off **Show folder index files** in **Settings → Appearance** to keep the sidebar tidy; the documents still exist and stay reachable from their folder page and from links.

Index files are never deletable on their own: if you delete the folder, its index goes to the trash with the rest of the subtree and comes back on restore. A folder that lost its index (for example one created before this feature existed) gets a fresh one the next time it is opened.
